## Главные риски, выявленные сравнением двух направлений

1. **`إِمْسَاكٌ`, печатная 30 (PDF 34):** оригинал прямо объясняет это как **`مَصْدَرُ أَمْسَكَ`**, с идеями удержания и воздержания. В исходной медицинской карточке `ind_noun_health_20261025_047` основное значение — **`صُعُوبَةٌ فِي إِخْرَاجِ الْبُرَازِ...`** (запор), а удержание названо только в примечании. **Это не ошибка одного из значений:** одинаково огласованное имя имеет разные употребления. Нельзя заменять медицинское определение книжным или создавать дубль. При расширении следует разделить значения и атрибутировать печатной странице только удержание/воздержание, а не медицинское описание.
2. **`أَمْرٌ` и `أَمَرَ`, печатная 30:** корпус содержит `أَمْرٌ` с двумя смыслами и правильным различением `أَوَامِرُ` / `أُمُورٌ`. Его стабильный ID сохранён. Глагол `أَمَرَ` на этих страницах **не подтвердился как та же полностью огласованная словарная форма**. Не объединять их по буквам без харакат. Внешняя сверка: [مجمع اللغة العربية بالقاهرة — أمر](https://www.arabicacademy.gov.eg/ar/search_engine/roots/أمر).
3. **`آمَنَ` / `آمِنٌ`, печатная 31:** обе формы уже имеются под **разными ID**, их нельзя объединять. Форму `آمِينَ`, произносимую после мольбы, и форму `أَمِينٌ` (достойный доверия) также нужно различать отдельно. Наличие `أَمِينٌ` не доказывает наличие `آمِينَ`.
4. **`أَنْتَ` / `أَنْتِ`, печатная 32:** существующий ID `level1_topic1_052` относится к **`أَنْتَ`**. Поиск без огласовок объединяет оба местоимения, поэтому существование `أَنْتِ` **не подтверждено** этим совпадением; не приписывать женскую форму мужскому ID автоматически.
5. **`أَنْجَزَ`, `أَنْتَجَ`, `إِنْجَازٌ`, `أَمْطَرَ`:** встречаются в нескольких исходных тематических JSON с разными legacy ID. По `corpus_manifest.json` первая запись является канонической. Новую карточку при расширении надо связывать с каноническим ID и существующим значением, не удаляя тематические ссылки и не подменяя синонимами отдельные смыслы.
6. Ни существующая медицинская `إِمْسَاكٌ`, ни имеющийся `أَمْرٌ` не дают автоматически проверенного анализа новых примеров из оригинала. `الصرف`, `النحو`, `الإعراب`, огласовки собственных предложений и отношения синонимии требуют независимого доказательства.
