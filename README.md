# Арабская академия — Android & iPhone

Flutter прототип приложения с двумя интерфейсами и **оригинальными черновыми** уроками арабского языка.
Название — рабочее; это самостоятельный проект, не официальное приложение издателя «العربية بين يديك».

## Сейчас реализовано
- Премиальная цветовая схема: изумрудный, тёплый кремовый, акценты бронзы.
- Русский UI и арабский текст Noto Naskh Arabic через `google_fonts` (для production следует встроить лицензированный шрифт в собственные assets, чтобы он работал офлайн; в архив шрифты не включены).
- Демо-переключение между интерфейсами ученицы и учительницы (НЕ безопасная авторизация).
- Восемь разделов, три учебных урока в первом разделе: диалоги, словарь, грамматика, тесты.
- Проверка вариантов ответов и **локальный** прогресс.
- Конструктор новых уроков учительницы: текст, задания, HTTPS-ссылка на MP4/HLS видео, черновик/публикация, бесплатный/платный статус, изменение/удаление; данные **только на одном устройстве**.
- Видеоплеер для прямых HTTPS-потоков; это не загрузчик файлов.

## Не готово к эксплуатации
Нет регистрации по телефону, серверной базы, синхронизации между телефонами, разграничения прав, платежей, загрузки видеофайлов, голосовых ответов, ИИ-проверки, уведомлений, полноценной админки, аудио или App Store/Google Play публикации. Платные экраны заблокированы как демо. Нельзя использовать тестовые роли для доступа к реальным данным.

## Требования
Flutter SDK >= 3.24, Dart >= 3.4, Android Studio для Android, Xcode на macOS для сборки iOS.

## Локальный запуск
```bash
flutter create --project-name arabic_academy --platforms android,ios .
flutter pub get
flutter analyze
flutter test
flutter run
```

`flutter create` требуется однократно: файлы, автоматически генерируемые Flutter SDK для Android и iOS, пока не включены. Они появятся в каталоге проекта на компьютере разработчика. Это стартовые исходники, а не готовый APK/IPA.

## Передача
Репозиторий **публичный на этапе разработки**; при закрытии проекта копии кода, уже опубликованного в сети, могут сохраниться. После приватизации выдавайте разработчикам доступ через GitHub permissions, выдавайте разработчикам доступ через GitHub permissions, используйте отдельные credentials для тестовой и production сред. Не храните ключи, пароли, реальные данные учениц и банковские сведения в репозитории.

## Контент
`assets/content/level1.json` и `docs/course_level1_draft.md` содержат собственные учебные тексты. Они ещё требуют независимой редакторской проверки арабских огласовок и переводов. Видеозаписи отсутствуют. Сканы, иллюстрации и аудио учебника издателя не включены.
## Дизайн v0.5 — оригинальная графика
- Главная ученицы: крупная сетка 2×2 с четырьмя самостоятельными сценами — ноутбук, задания, наушники, карточки слов.
- Приветствие, курс и кабинет учительницы: разные оригинальные фотографии. Никаких вырезок из изображений референсных экранов.
- Уникальные матовые 3D-иконки используются в разделах, управлении и нижней навигации.
- Для уменьшения размера репозитория авторские изображения сохраняются в проверенном текстовом атласе `assets/_embedded/v05/atlas.part*.txt`; скрипт `python3 scripts/restore_original_artwork.py` извлекает 17 отдельных WebP-ресурсов в `assets/images/` и сверяет SHA-256.
- GitHub Actions запускает восстановление ДО `flutter analyze`, тестов и APK-сборки.
- В существующих исходных файлах от старых версий могут быть исторические картинки, но в версии v0.5 рабочие `feature_*` и `icon_*` заменяются при сборке новыми оригиналами.
