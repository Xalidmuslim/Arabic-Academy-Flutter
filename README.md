# «Байна Ядайк» — отдельный арабо-арабский толковый словарь

**Текущая демонстрационная база: 118 словарных статей.** Для первой темы есть 62 позиции учебного вспомогательного списка; для второй темы «الْأُسْرَةُ» — 36 позиций, включая несколько слов, повторяющихся между темами.

### Источники и статус
- Первая тема: https://arabvocab.com/book/1/chapter/1/intro
- Вторая тема: https://www.isalkini.com/6837/
- Обе привязки **предварительные**, официальные списки издательства «العربية للجميع» не сверены.
- Арабские толкования, словосочетания, грамматика и примеры написаны самостоятельно, не перенесены из книжных текстов. Не считать словарные статьи готовыми к публикации без редакторской проверки.
- Разные арабские значения объясняются простыми арабскими словами, без русских переводов.

### Интерфейс
Русские подписи, 7 разделов карточки, поиск без огласовок, переход по арабским словам в определении, отдельные избранные и закладки, копирование слова, озвучка системным TTS, светлая/тёмная тема, масштаб арабского шрифта, постоянно видимая нижняя навигация и сохранение позиции при возврате в список. Фильтры книги 1, темы 1 и 2.

### Android
Это **отдельное демонстрационное приложение**, рабочее основное приложение в других ветках не затронуто. Для сборки используется GitHub Actions `dictionary-apk.yml`; APK — `dist/bayna-dictionary-demo.apk` после успешной публикации. Работоспособность на физическом телефоне требует проверки.
