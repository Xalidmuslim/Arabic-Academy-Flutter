# Байна Ядайк · العربية بين يديك

Нативное Flutter-приложение изучения арабского языка для Android/iOS. Разработка продолжается в существующем репозитории; `main` не меняется автоматически.

Версия `0.7.0+7`: авторское офлайн-обучение, мобильный конструктор, серверные школьные модули и интеграции. Это не заявление о завершённом коммерческом запуске. Фактическая готовность, результаты проверки и зависимости от аккаунтов владельца: [отчёт поставки](docs/delivery-report.md).

## Запуск

Требуются Flutter **3.35.7**, полный JDK **17**, Android SDK **36**; для iOS — macOS, Xcode **26.3** и CocoaPods, deployment target iOS 15+. Нативные проекты уже включены; повторное `flutter create` не требуется.

```bash
flutter pub get --enforce-lockfile
python3 scripts/verify_assets.py
python3 scripts/verify_native_config.py
flutter analyze --no-pub
flutter test --no-pub
flutter run
```

Без Supabase-ключей работают локальные авторские учебные материалы, прогресс и демо-конструктор. Реальная авторизация/школа использует только серверные роли. Платные данные не открываются локальным переключателем.

```bash
flutter run --dart-define=SUPABASE_URL=https://YOUR_PROJECT.supabase.co \
  --dart-define=SUPABASE_ANON_KEY=YOUR_PUBLIC_KEY
```

Публичный клиентский ключ не является административным. Никогда не передавайте `service_role`, LiveKit secret, P8, store service-account или STT-ключ через `--dart-define`.

Старый учебный JSON сохранён без изменений. Новые материалы — авторские, не дословное содержание издательского учебника. PDF/выбранное издание и права на воспроизведение не предоставлены. Изображения референсов не встраиваются и не вырезаются; новые самостоятельные ресурсы находятся в `assets/artwork`, PNG-оригиналы — в `design/originals`. Исторические изображения остаются в Git, но не входят в asset-конфигурацию приложения.

Не коммитьте реальные сведения учениц, секреты, keystore и пароли. Роли и оплаченный доступ выдаёт сервер. Deployment/test signing не объявляется production signing. Правила региональных платежей и хранения персональных данных требуют настройки владельцем до запуска.
