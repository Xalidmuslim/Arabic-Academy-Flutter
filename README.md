# «Байна Ядайк» — арабо-арабский толковый словарь

**Демонстрационная база: 165 авторских словарных статей.**
Первая тема первого учебника: 62 позиции. Вторая «الْأُسْرَةُ»: 36 позиций. Третья «السَّكَنُ»: 52 позиции. Повторяющиеся леммы имеют одну карточку и несколько привязок к темам.

### Принципы и источники
- Интерфейс на русском; все словарные значения, примеры, грамматика, синонимы и антонимы — на арабском с огласовками.
- Семь разделов: значения, синонимы, антонимы, грамматика, словосочетания, примеры в предложениях, особенности употребления.
- Значение **объясняется простыми арабскими словами**, а не заменяется единственным синонимом. Не применимые формы и антонимы не выдумываются.
- Первая тема: https://arabvocab.com/book/1/chapter/1/intro
- Вторая тема: https://www.isalkini.com/6837/
- Третья тема: https://www.isalkini.com/6840/
- Источники вспомогательные; **с официальным глоссарием в конце учебника ещё не сверено**. Порядок слов в теме 3 — авторская нумерация по категориям вторичного списка, а не подтвержденный издательский порядок. Это собственные учебные определения и примеры, требующие лексикографической редакции.

### Android
Русские вкладки «Словарь», «Избранное», «Закладки», «Настройки», темы оформления, регулируемый арабский шрифт, копирование слова, офлайн-поиск без огласовок, произношение Android TTS, клик по арабскому слову, возврат жестом без потери позиции списка. Фильтры «Книга 1 · Тема 1–3».

Рабочее приложение «Байна Ядайк» не изменяется: это отдельная демонстрационная ветка `codex/bayna-dictionary-demo-apk-20261024`.

В GitHub Actions `dictionary-apk.yml` собирается ARM64 Release APK, файл `dist/bayna-dictionary-demo.apk` публикуется после успешных проверок.
