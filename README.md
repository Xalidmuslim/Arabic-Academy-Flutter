# Словарь «Байна Ядайк» — независимое приложение

**Текущая демонстрационная база: 87 словарных статей**, в том числе 62 лексических единиц из первого раздела по вспомогательному учебному списку.

Русский интерфейс; словарные значения и все лексические материалы на арабском, с огласовками. У каждой статьи семь разделов: значения (собственные простые арабские объяснения), синонимы, антонимы, грамматика, словосочетания, примеры и особенности употребления. Неприменимые категории оставляются пустыми. По арабским словам в тексте возможен переход к другой имеющейся статье. Есть офлайн-поиск и избранное.

В списке текущей главы источником служит независимый вспомогательный каталог: https://arabvocab.com/book/1/chapter/1/intro . **С официальным печатным словарём эта последовательность ещё не сверена.** Определения написаны самостоятельно; текст издательства не воспроизводится. Общее количество лексических единиц серии по издательству — 3325. Не утверждаем, что полный словарь восьми частей уже готов.

Исходное приложение не изменяется: разработка отдельного APK идёт в ветке `codex/bayna-dictionary-demo-apk-20261024`.
