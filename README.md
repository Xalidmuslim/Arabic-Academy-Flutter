# Байна Ядайк — арабо-арабский толковый словарь

Демонстрационный APK с 37 авторскими словарными статьями, не полный словарь восьми частей. Русский используется только в интерфейсе. Арабские определения простыми словами с огласовками; разные значения вынесены отдельно. Семь разделов каждой карточки. При нажатии на арабское слово открывается его словарная статья, если она есть; в противном случае отображается уведомление. Полная база и сверка с книгами ещё впереди.
