# Контрольная точка словаря — 1483 статьи

Дата: 25 октября 2026.

**Зафиксированный результат:** 1483 уникальные словарные статьи после объединения точных дублей арабских заголовков.

**Тематический охват:** 48 черновых подборок: 16 тем уровня 1, 16 тем уровня 2 и 16 тем уровня 3. Уровень 4 не заполнен. **Ни один уровень ещё не выверен как полный перечень слов официального учебника.**

Заголовки тем уровня 3 сверены с оглавлением; слова и объяснения составлены самостоятельно и требуют сопоставления с оригинальным словарём в конце соответствующих частей. Не заявлять, что все слова учебника уже внесены.

## Что сохранено
- `assets/data/corpus_manifest.json`: 14 файлов JSON в стабильном порядке.
- `assets/data/entries.json`: исходная база 806 статей.
- `assets/data/entries_level2_07_08.json` ... `entries_level2_15_16.json`: пять отдельных файлов.
- `assets/data/entries_level3_01_02.json` ... `entries_level3_15_16.json`: восемь файлов, по две темы.
- Проверка `Dictionary content validation only`: GitHub Actions запуск `40177477525`, `success`, **5 tests**, **1483 entries**.
- Повторяющиеся точные заголовки объединяются, прежние ID слов сохраняются.
- Новые записи имеют арабское объяснение, грамматику, словосочетание и пример. Некоторые синонимы/антонимы есть, но большая часть полей `synonyms`, `antonyms`, `usage_note_ar` и `additional_meanings_ar` ещё требует содержания и редакторской проверки.
- Свободное скачивание исходных PDF не означает права на копирование их текстов и готовых словарных статей.
