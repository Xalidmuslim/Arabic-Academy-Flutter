## Результаты аудита

Исходная версия содержит 3 оригинальных черновых урока и 8 авторских демонстрационных разделов. PDF, лицензированное аудио, подтверждение издания и прав на учебник отсутствуют во всех найденных ветках. Эти данные сохраняются как авторские материалы, а не объявляются структурой издательского курса. Точная структура учебника импортируется из проверенного лицензионного манифеста с указанием издания, томов, разделов и страниц; неизвестные номера не выдумываются.

`lib/main.dart` объединяет хранение, навигацию, обучение, редактор и видеоплеер. Прогресс: ключ `completed`; материалы: `teacher_lessons`; welcome: `welcome_seen` в SharedPreferences. Существующие ключи и ID сохраняются. Новый документ состояния версионируется; исходный JSON резервируется до миграции. Повреждённые записи не удаляются. Демонстрационные данные никогда автоматически не публикуются в реальный аккаунт.

Старые `import_reference_art.py` и соответствующий workflow вырезают изображения из референса. `restore_original_artwork.py` восстанавливает малый атлас. В рабочей версии они отключаются; новая графика создаётся отдельными оригинальными файлами. Учебные JSON и пользовательские материалы не удаляются.

Риски производительности: шрифты Google Fonts через сеть при первом запуске, декодирование растров без ограничения размера, повторяющиеся тяжёлые иллюстрации, вложенные shrinkWrap-списки, глобальные перестроения. Новая тема использует локальные Manrope/Noto Naskh Arabic, ограниченные decode размеры, ленивые списки, короткие анимации без blur. Измерения release/profile фиксируются отдельно: отсутствие устройства не заменяется вымышленными цифрами.

## Модули

1. `lib/core`: AcademyState, совместимость локального хранения, события, настройки, очередь синхронизации, закладки и словарные повторения.
2. `lib/features/exercises`: независимые модели/проверка 25 типов, ответы, попытки и виджет исполнения. Автоматическое сравнение и ручная проверка разделены.
3. `lib/features/learning`: курсы, шесть шагов урока, словарь, грамматика, поиск и прогресс.
4. `lib/features/teacher`: сохранённый мобильный редактор, структурированные блоки/упражнения, черновики, копирование, импорт/экспорт.
5. `lib/services`, `lib/features/integrations`: Supabase OTP и данные, запись/воспроизведение, загрузки, LiveKit, покупки. Недоступная интеграция возвращает понятную ошибку, а не фиктивный успех.
6. `lib/ui`: локальные шрифты, дизайн-токены, матовые поверхности, доступные кнопки и оригинальные ассеты.
7. `supabase`: PostgreSQL-миграции, RLS, приватное хранилище, Edge Functions, SQL-тесты доступа.

## Сервер и доверие

PostgreSQL/Supabase: телефонный OTP через настроенного SMS-провайдера; роли только из серверных таблиц. Демо-роль управляет только локальным контуром. Серверная RLS проверяет владельца, назначение учительницы, публикацию и действующие права доступа. Ключ service_role, LiveKit secret и ключи верификации магазинов существуют только на сервере.

Покупка даёт право на конкретный курс; подписка — только на явно заданный набор услуг/курсов до expires_at. Клиентский флаг success не выдаёт доступ. Проверенные покупки обрабатываются идемпотентно. Отмена доступа не удаляет прогресс. Ответы для закрытых серверных тестов не выдаются клиенту как источник истины.

Синхронизация: события с UUID, уникальным ключом и серверным временем; повторная доставка безопасна. Локальные попытки/черновики сохраняются до подтверждения; события append-only. Материалы редактируются с версией, конфликт не затирает чужую версию. Локальные бесплатные авторские материалы доступны офлайн. Кэширование платных материалов требует серверного разрешения и срока лицензии.

## Визуальный контракт

Кремовая матовая поверхность, ivory `#F8F4E8`, beige `#EADFCB`, sand `#D6C8AE`, sage `#A7A68D`, olive `#5F7A47`, deep olive `#3E5B33`, emerald `#234A3A`, bronze `#8B6F47`, gold `#C9A06B`. Радиусы 16–28dp, два мягких слоя теней, интерактивные зелёные кнопки. Главная: название/подзаголовок, уведомления/настройки, 4 крупные плитки 2×2, компактная карточка продолжения, постоянная навигация. Иллюстрации: учебные книги, заметки, буквы, диаграммы, современные кабинеты. Религиозные образы и старые вырезки запрещены. Арабский текст остаётся Text с харакатами, RTL и высотой строки >=1.65.

## Критерии приёмки

Analyze и тесты проходят без отключения проверок; неверный ответ не даёт завершить урок; восстановление локальных данных сохраняет ID и неизвестные поля; роли/закрытый курс/чужая ученица/поддельная покупка проверяются серверными тестами. Нативные папки Android/iOS в репозитории, APK/AAB собираются из нового кода. iOS unsigned проверяется на macOS CI; подпись требует Apple-аккаунта. Статус каждого внешнего сервиса и невыполненного требования приводится честно в отчёте передачи.
