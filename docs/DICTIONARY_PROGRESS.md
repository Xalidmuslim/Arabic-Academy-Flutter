## Зафиксированная контрольная точка

- **554 уникальные словарные статьи** на арабском языке.
- Есть предварительные списки для **16 тем первого уровня** из вспомогательных источников.
- Старые статьи не перезаписывались ради новых привязок. Если слово повторяется в нескольких темах, хранится один `id`, но несколько `book_references`.
- Основные поля: `arabic`, `meaning_ar`, `additional_meanings_ar`, `synonyms`, `antonyms`, `grammar`, `collocations`, `examples_ar`, `usage_note_ar`.
- Для новых статей написаны собственные краткие арабские объяснения (не только синонимы), грамматика, словосочетания и примеры; некоторые синонимы/антонимы/примечания намеренно оставлены пустыми, если нет подтверждённых сведений.
- **Статус: черновая база, без сверки с печатным официальным словарём, без полноценной арабской редакторской вычитки**. Количество уникальных статей не равно количеству слов в официальном глоссарии.
