# Арабо-арабский словарь «Байна Ядайк» — журнал наполнения

Состояние на 25 октября 2026 года.

## Зафиксированная контрольная точка

- **554 уникальные словарные статьи** на арабском языке.
- Есть предварительные списки для **16 тем первого уровня** из вспомогательных источников.
- Старые статьи не перезаписывались ради новых привязок. Если слово повторяется в нескольких темах, хранится один `id`, но несколько `book_references`.
- Основные поля: `arabic`, `meaning_ar`, `additional_meanings_ar`, `synonyms`, `antonyms`, `grammar`, `collocations`, `examples_ar`, `usage_note_ar`.
- Для новых статей написаны собственные краткие арабские объяснения (не только синонимы), грамматика, словосочетания и примеры; некоторые синонимы/антонимы/примечания намеренно оставлены пустыми, если нет подтверждённых сведений.
- **Статус: черновая база, без сверки с печатным официальным словарём, без полноценной арабской редакторской вычитки**. Количество уникальных статей не равно количеству слов в официальном глоссарии.

## Контроль сохранности

- Рабочая ветка: `codex/bayna-dictionary-demo-apk-20261024`.
- Отдельная резервная ветка для этого этапа: `backup/bayna-dictionary-554-20261025` (не изменять при дальнейшем наполнении).
- Источник: `assets/data/entries.json`.
- Валидатор без сборки: `python3 tools/validate_dictionary.py`.
- GitHub Actions: `Dictionary content validation only` — срабатывает при правках базы и валидатора. Сборка APK отключена на push; `Dictionary APK build` доступна **только вручную** через `workflow_dispatch`.

## Следующие задачи

1. Сверить уровень 1, 16 тем с оригинальными указателями слов в обеих частях и добавить пропуски. Привести огласовки, роды, множественные числа и глагольные формы к единому стандарту.
2. Пройти редактирование значений и случаев многозначности, прежде всего глаголов и омографов.
3. Заполнить недостающие **подтверждённые** синонимы, антонимы и особенности употребления, избегая фиктивных антонимов.
