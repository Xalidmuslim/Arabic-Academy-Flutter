## Источники и ограничения

Издатель подтверждает структуру четвёртого уровня: два учебника, 16 разделов, список слов каждого раздела в конце уровня:
https://platform.arabicforall.net/ar/store/product/arabic-at-your-hands-student-book-4-1

**ВНИМАНИЕ:** точные названия и состав слов разделов четвёртого уровня в этой базе **пока не сверены с издательским словарём**. Новые статьи самостоятельно написаны и имеют метаданные `official_end_glossary_checked:false` и `chapter_title_not_verified:true`. Их номера — только редакторская сортировка, пока не будет проведена сверка. Аналогично по остальным трём уровням неполон охват официальных словарных списков. Не выдавать эти 64 подборки за точную копию структуры оригинальных восьми книг.

Арабские объяснения, примеры, синонимы и огласовки ещё требуют ручной филологической редактуры. Не все статьи завершены по всем семи разделам. Отсутствие прямого антонима допустимо и не должно маскироваться выдуманным словом.

## Дальнейший порядок

1. **Сверить реальный словарь издателя** по каждому уроку во всех восьми книгах. Использовать материалы с законным правом доступа; не копировать чужие тексты/разъяснения без разрешения.
2. Дозаполнить пропущенные учебные слова собственными чёткими арабскими определениями, начиная с самого низкого уровня сложности.
3. Вычитать морфологию, огласовки, множественные значения, глагольные формы, согласование синонимов и антонимов.
4. Дополнить `additional_meanings_ar`, `synonyms`, `antonyms`, `usage_note_ar`, не изобретая несуществующих отношений.
5. Проверить Android/Flutter: поиск, нажатие слов внутри определений, пользовательскую клавиатуру, размер шрифта, день/ночь, сохранение позиции, избранное и постоянную нижнюю навигацию.
6. **Не собирать APK автоматически**, пока пользователь не попросит после завершения корпуса.

Команда быстрой проверки: `python3 -m unittest discover -s tools -p "test_*.py" && python3 tools/validate_dictionary.py`.
