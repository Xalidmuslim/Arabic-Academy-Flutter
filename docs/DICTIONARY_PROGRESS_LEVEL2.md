# Контрольная точка словаря — 1 136 статей

Дата: 25 октября 2026.

## Проверенный технический результат

- **1 136 уникальных словарных статей** после объединения повторяющихся полностью огласованных заголовочных слов.
- **32 предварительные тематические подборки**: 16 первого и 16 второго уровня. Тематическая подборка не равна полному официальному списку слов из печатного учебника.
- Восьмикнижная серия в целом **не завершена**: предварительно затронуты первые два уровня из четырёх, причём они ещё не сверены с печатными глоссариями.
- Словарное содержимое на арабском языке; русский остаётся языком интерфейса.
- Повторяющееся слово сохраняет исходный `id` и дополнительные привязки `book_references`, чтобы не потерять избранное/закладки.
- Каждая самостоятельно составленная новая статья включает `meaning_ar` как полноценное объяснение слова на арабском, `grammar`, `collocations`, `examples_ar`. Поля синонимов, антонимов и примечаний к некоторым новым словам оставлены пустыми до проверки, чтобы не выдумывать неподходящие значения.
- ВАЖНО: тексты требуют арабской редакторской вычитки; многозначность и полная система семи разделов заполнены не во всех статьях.

## Структура исходников

Загрузчик сначала читает `assets/data/corpus_manifest.json`, затем получает файлы в записанном порядке:

- `assets/data/entries.json` — контрольная база до разбиения, включает 806 статей.
- `assets/data/entries_level2_07_08.json`
- `assets/data/entries_level2_09_10.json`
- `assets/data/entries_level2_11_12.json`
- `assets/data/entries_level2_13_14.json`
- `assets/data/entries_level2_15_16.json`

Загрузчик Dart `decodeAndMergeCorpora` объединяет повторяющиеся заголовки, не перезаписывает каноническое первое определение и дополняет привязки к темам. При разном огласовании омографы не смешиваются.

Проверка без APK: `python3 -m unittest discover -s tools -p "test_*.py" && python3 tools/validate_dictionary.py`.
GitHub Actions `Dictionary content validation only` завершился с `success`: 1 136 уникальных статей.
