## Boundaries and next QA tasks

1. **Do not deduplicate** different vowelings that represent genuinely different meanings, e.g. `سَلَطَةٌ` (salad) vs `سُلْطَةٌ` (authority), `كُلِّيَّةٌ` (faculty/college) vs `كُلْيَةٌ` (kidney), or a verb vs its verbal noun.
2. **201 groups need editorial triage** for alternate valid vocalizations vs remaining mistakes. Archived machine-readable audit artifact is attached to the GitHub Actions run (14-day retention). The corpus tester audits all files, but cannot judge semantic equivalence by itself.
3. Review the **quality of definitions, examples, collocations, gender/plural grammar and technical terminology** manually; current checks cover formal shape and known regression cases only.
4. If a sourced lesson entry is updated, preserve `book_references` and ordering. Textbook-specific alignment has not been checked against publisher materials.
5. **No APK build** was run, by design. No modifications to the separate textbook application.
