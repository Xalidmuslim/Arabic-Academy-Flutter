- Объединение всех JSON-файлов управляется `assets/data/corpus_manifest.json`; зарегистрировано **37 частей** словарной базы.

## Права
Издатель «العربية للجميع» сообщает о четырёх уровнях и восьми студенческих книгах. Наличие книги в открытом доступе само по себе не даёт право копировать готовые авторские определения. Добавленные объяснения написаны самостоятельно, их принадлежность к учебнику не подтверждена.
