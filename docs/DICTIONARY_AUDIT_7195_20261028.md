## Границы работы

Это **отдельное приложение арабо-арабского словаря**, а не приложение учебника «العربية بين يديك». Созданные самостоятельно определения **не выдаются за сверенные с официальным текстом**. Новые подтверждённые отсылки к книге не добавлялись. **APK не собирался.**

Следующий шаг: ручная проверка групп из полного отчёта, начиная с вероятных ошибочных огласовок. Приоритет — точность лексических значений и научной терминологии; автоматически сливать одинаковые без огласовок слова нельзя.
