## Подтверждённые регрессии и исправления

1. **Потеря дополнительного значения:** Python-объединение корпуса сохраняло содержательное вторичное значение `meaning_ar`, а Flutter-объединение — нет. Теперь `decodeAndMergeCorpora()` добавляет более позднее содержательное определение в `additional_meanings_ar`, сохраняет исходный ID и предотвращает повторы.
2. **Ошибочная лексема при нажатии на арабский текст:** прежний поиск отбрасывал огласовки после префикса, например `بِالْعِلْمِ`, и мог открыть `عَلَمٌ` вместо `عِلْمٌ`. Теперь первыми проверяются формы с огласовками после отсечения типичных приставленных частиц и артикля.
3. **Неоднозначный запрос без харакатов:** вместо произвольного первого совпадения приложение возвращает отсутствие точного выбора, если у формы несколько разных огласованных заголовков. Проверенный пример — `علم`.
4. **Порядок статей:** `sortWordsByBookOrder()` раньше не учитывала `book_references` при отсутствии устаревшего единственного `book_reference`. Теперь сортировка учитывает современный список и сохранённую позицию в теме.
5. **Неотображаемая тема в карточке:** `WordTile` показывал `Книга · Тема` только из старых полей; теперь корректно читает данные из `book_references`, не изменяя сами карточки.
